# 我們的家庭旅行手帳

[開啟網站](https://nickwang0317.github.io/family-travel-hub/)

這是我們在對話中一起整理的家庭旅行網站。使用者提供新的安排，助理更新 GitHub，網站呈現目前的旅程與下一次需要提供的資訊。網誌通行碼只提供一般訪客的頁面提示；repo 公開，網誌文字與通行碼仍能從原始碼查看，不適合放敏感內容。

## 使用方式

- **今天**：直接展開當日行程、導航與出門清單。
- **今日網誌**：與今日行程分開，收錄今天分享的照片與生活片段；輸入三組家人通行碼其中一組即可瀏覽。
- **接下來**：直接展開未來行程；富國島有登機證風格的準備提醒板。
- **待補提醒**：顯示已知資料、訂購狀態及缺少的資訊。可複製待補清單，貼回對話請助理整理。
- **我們的對話筆記**：呈現目前已記下的安排、想跟你確認的問題與助理提醒。直接回覆對話，助理會更新網站並收起已解決的問題。
- **走過的日子**：保存旅程、照片與每日網誌，每趟有自己的分享網址。歷史網誌需輸入家人通行碼；首頁、行程資訊與相簿照片保持公開。

機票、飯店與接送資料由對話維護，頁面沒有編輯、匯入或匯出功能。提醒會在開啟網站時顯示；沒有背景推播。出門清單的勾選保存在該裝置的瀏覽器。

## 長期合作方式

你在對話中告訴助理新的旅程資訊、臨時改變或偏好，助理會整理進網站。已確認資訊、待確認問題與助理建議分開呈現；回答後就解決相應問題，不反覆提醒。這套方式寫在 `AGENTS.md`，接續工作以網站資料與 Git 紀錄為依據。

開著網站時，`site-updates.js` 每分鐘檢查一次 `site-version.json`；切回頁面時也會檢查。新版本部署完成後，自動載入，保留目前分類、旅程網址與閱讀位置。頁面底部可以查看最近更新。問題透過我們的對話回覆，沒有網頁回覆表單。

## 維護位置

| 檔案 | 內容 |
| --- | --- |
| `index.html` | 旅程清單、既有網誌、當日與未來行程呈現 |
| `travel-prep.js` | 富國島已確認資料、待補提醒、對話清單與行程 |
| `travel-prep.css` | 準備提醒板的樣式與手機版排版 |
| `site-updates.js` / `site-version.json` | 開啟頁面的新版檢查與版本值 |
| `photos/` | 既有旅行照片 |

### 更新富國島

1. 依使用者提供的資料，更新 `travel-prep.js` 的 `preparation`。
2. 訂購狀態 `booked`：`true` 已確認、`false` 明確尚未安排、`null` 尚未確認狀態。知道航班時間不等於已完成訂票。
3. 未知欄位保留空字串，不臆測。更新 `updatedOn` 為本次整理日期。
4. 待補清單依欄位自動計算，完整項目收進「已收好」，同一份資料也會出現在行程。
5. 確認每日活動後，加到 `index.html` 中富國島旅程的 `dailyPlans`，每筆使用 `date`、`time`、`title`、`desc`，可附 `links`。航班時間依各機場當地時間；富國島行程以越南時間篩選當日安排。

GitHub Pages 直接發布 `main` 的靜態檔案。更新時一起提交 HTML、JS 與 CSS，保留既有照片與其他旅程。

### 每次發布

同步修改 `index.html` 的 `site-revision`、`site-version.json`、資源網址版本參數與 `siteUpdates` 更新紀錄，使用新的唯一版本值。一般旅程的 `conversation` 包含 `updatedOn`、`confirmed` 與 `notes`；每則筆記的 `kind` 使用 `question` 或 `reminder`，問題解決後刪除或設 `resolved: true`。保存已確認資料到行程，而不只修改提醒文字。
